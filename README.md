# SmartBase-Restaurant-Finder
This project will create a cooperative restaurant finding website called SmartBase. Users will be able to search for restaurants via a web interface based on criteria such as food type, price, location, and rating. In the absence of a restaurant that satisfies all criteria exactly, the system relaxes the search and offers the closest options instead of returning no results. We will use numeric distance functions for price, rating, and location, and a type abstraction hierarchy (TAH) for food types to measure closeness. Results will be ordered by their closeness to the user’s original request. The goal is to have a system that is easy to use and always gives useful results.
